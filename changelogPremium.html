Changelog

Track the latest updates, improvements, and security enhancements

Welcome to the Screen Lock Builder Premium changelog! This page documents all major updates, new features, security enhancements, and improvements to our premium Windows screen locker builder. Stay informed about the latest developments in Screen Lock Builder Premium's journey to provide the most advanced and secure screen locking solution for Windows.

Latest Release: The October 25, 2026 update (Version 2.2) is a big one – a completely redesigned, modern look for the whole Builder, a new Telegram Connection tab that lets you lock and unlock remotely, a much more reliable file locker, lifetime licensing, one-click download of the latest version, and many smaller improvements and fixes.

Update Version: 2.2 October 25, 2026

Modern Redesign, Telegram Control & Many Fixes

Brand-New Modern Look

  • The entire Builder has been rebuilt with a fresh, modern dark design with subtle blue tones. It looks cleaner and more professional while working exactly the same way you are used to.
  • The tabs now sit along the top of the window, so everything is easier to find.
  • New custom window frame with its own styled close and minimize buttons, instead of the plain old Windows frame.
  • The app title now reads “Screen lock builder Premium” with a small “dev-offcode.com” underneath.

New: Telegram Connection

  • A brand-new “Telegram connection” tab lets you link the lock to your own Telegram bot, with a clear step-by-step guide built right in.
  • Control the lock remotely from Telegram: send /close-screenlock to open (unlock) the screen lock, and /open-screenlock to bring it back up – from anywhere.
  • Your locked computer sends you a Telegram message when it comes online, and a “Send test” button lets you confirm everything works before you build.
  • Only your own chat can send commands, so nobody else can control your lock.

A More Reliable File Locker

  • Blocked programs are now properly hidden the moment they are opened, so you only see the password window – even for multi-window apps that used to slip through.
  • Entering the wrong password, or pressing Cancel, now fully closes the blocked program instead of leaving it running.
  • Entering the correct password unlocks everything and closes the locker cleanly, so your programs work normally again.
  • Fixed an issue where the locker could refuse to start on some systems.

Easier Program & File Selection

  • The program picker now automatically detects the programs installed on your computer, so you can add them with one click.
  • The lists now scroll properly, so nothing gets cut off when the window is small.
  • A small pop-up note appears in the corner to confirm each time you add something to the block list.
  • The folder list now shows each folder’s full path underneath its name, so it is clear exactly what you are locking.
  • Cleaner, more modern lists and clearer buttons throughout the picker.

New: Choose Your Output Icon

  • You can now choose the icon for the lock files you create. Both the Lock screen and Lock files tabs have a new “Output file icon” option with three choices: keep the default Windows icon, pick your own icon from your computer (an .ico file, or a PNG, JPG or BMP image that is converted automatically), or let the Builder create a random modern icon for you.
  • The Builder’s own app icon stays exactly the same and cannot be changed.

Updates Tab & Other Improvements

  • The Updates tab now shows this changelog live from the website, so you always see the latest news inside the app.
  • Your license now shows as a lifetime license (“Expires: Never”) for every customer.
  • A “Download latest version” button on the Updates tab opens the current download link in your browser. Your license and settings are never touched.
  • The download link is served from our servers, so we can update it without you needing to reinstall the Builder.
  • System tray support: you can now minimize the Builder to the system tray, and if Builder login is enabled, reopening it from the tray asks for your password first.
  • Fixed a display glitch where the lock icon showed up as scrambled characters.
Update Version: 2.1 December 21, 2025

Lock Screen Tab Updates

Service Startup

  • Service startup: The application starts as a Windows service, allowing it to launch faster during system boot.

Safe Mode Support

  • Startup in Windows Safe Mode: The application also starts in Safe Mode, making it more difficult to remove.
