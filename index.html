Seven tools covering encryption, device security, automation and private communication. Each one is documented on its own page, with pricing, requirements and release notes kept up to date.

OffCrypt for Android

Encrypt messages and files on your phone, fully offline. Send self-destructing messages that disappear after reading. Free and open source (GPL-3.0).

OffCrypt Desktop for Windows

Encrypt messages and files on your Windows PC, fully offline. Send disappearing messages, manage contacts and identities, and keep all your data on your own machine.

Screen Lock Builder

Build your own Windows screen locker without writing code. Set a custom message and password, block Task Manager, and choose when it locks or unlocks. Saved as a portable app you can run anywhere..

Automation Tool

Automate repetitive tasks on your Windows PC. Describe what you want in plain English, let AI build the script, and run it on a schedule. Reads text on your screen and clicks for you..

Free, self-hosted remote control for Windows. Watch the live screen, transfer files, manage tasks and open a remote terminal from any browser.

A free, self-hosted chat that runs over the Tor network. Create password-protected or hidden rooms, share one link, and let guests join with only Tor Browser. Messages are encrypted in the browser and expire automatically.
