Frequently asked questions

Does OffCode software collect telemetry?

The offline apps collect no user data. Paid licences use a hardware ID only for activation.

  • OffCrypt Android, OffCrypt Desktop, Screen Lock Builder (free)No data collected. Work fully offline and never contact external servers.
  • Screen Lock Builder PremiumCollects only your hardware ID (HWID) to activate and verify the licence.
  • Automation ToolCollects no personal data or usage information; automations run locally. The optional AI Script Builder sends your prompt to the LLM provider you choose (or a local Ollama).
  • Web Remote Control, Tor ChatSelf-hosted: they run on your own server, and you control hosting and data.
